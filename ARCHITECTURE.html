Request & Data Flow

Complete Request Lifecycle

1
User Interaction (Frontend) User selects filters or navigates to a page. Vue component updates reactive state via ref() and computed() properties.
2
API Request Frontend calls api.js which uses Axios to send HTTP GET request with query parameters to backend at localhost:8001.
3
Route Handling (Backend) FastAPI router matches the endpoint (e.g., /api/inventory) and invokes the corresponding handler function with filter parameters.
4
Data Filtering Handler applies filters (warehouse, category, status, month) using apply_filters() and filter_by_month() helper functions.
5
Pydantic Validation Filtered results are validated against Pydantic models (InventoryItem, Order, etc.) for type safety and structure consistency.
6
Response Generation Valid data is serialized to JSON and returned with appropriate HTTP status code (200 for success, 404 for not found, etc.).
7
Frontend Rendering Axios promise resolves with response data. Vue component updates refs/computed properties, triggering re-render. UI displays new data with charts and tables.

API Endpoints

GET/api/inventory
Filters: warehouse, category
GET/api/inventory/{item_id}
Get single inventory item
GET/api/orders
Filters: warehouse, category, status, month
GET/api/orders/{order_id}
Get single order details
GET/api/dashboard/summary
Filters: warehouse, category, status, month — KPIs and overview data
GET/api/demand
Demand forecasts — No filters
GET/api/backlog
Backlog items — No filters
GET/api/spending/summary
Overall spending metrics
GET/api/spending/monthly
Monthly spending breakdown
GET/api/spending/categories
Spending by product category
GET/api/reports/quarterly
Quarterly performance reports
GET/api/reports/monthly-trends
Monthly trend analysis
